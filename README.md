# ربات پست‌گذاری شهر سفال — نسخه ۳

انتشار خودکار روزانه‌ی محصولات (بله + تلگرام + روبیکا) با عکس و متن Gemini، و **مدیریت کامل فقط از داخل تلگرام**.
بله و روبیکا فقط مقصد انتشارند و پیام مدیریتی از آن‌ها خوانده نمی‌شود.

## ارتقا از نسخه‌ی قدیمی (به ترتیب)
1. در Supabase > SQL Editor کل `schema.sql` را اجرا کنید (تکرارش بی‌خطر است و داده‌ها دست‌نخورده می‌مانند).
2. فایل `bot.py`، `schema.sql`، `README.md` و `.env.example` را در مخزن GitHub جایگزین کنید. متغیرهای Render همان قبلی‌اند؛ فقط مطمئن شوید `TELEGRAM_TOKEN`، `TELEGRAM_TARGET` و `ADMIN_USER_IDS_TELEGRAM` تنظیم است.
3. فقط **یک** نمونه‌ی سرویس روی Render اجرا شود. بعد از دیپلوی در تلگرام `/start` بزنید. اگر دیتابیس به‌روز نباشد، همان‌جا هشدار می‌دهد.

## قابلیت‌های پنل (`/start`)
- **محصولات:** صفحه‌بندی، فیلتر فعال/غیرفعال، جستجوی نام، ویرایش نام/تصویر/لینک، فعال‌سازی، حذف (با تأیید)، افزودن با لینک.
- **صف انتشار:** افزودن محصول، لغو، تلاش مجدد (فقط مقصدهای ناموفق)، انتشار فوری، پیش‌نمایش، انتشار دوباره. محصول تکراری در صف پذیرفته نمی‌شود.
- **ویرایش پست:** متن دلخواه، تغییر تصویر (عکس یا آدرس)، و «۳ متن AI» برای انتخاب بهترین.
- **زمان‌بندی اختصاصی:** دکمه‌های آماده یا تاریخ دلخواه (`1405/09/10 18:30`، `18:30`، `+45`، `+2h`، میلادی هم قبول است).
- **تقویم انتشار:** نمای هفتگی با تاریخ شمسی (ساعت‌های چرخه‌ای + محصولات زمان‌بندی‌شده).
- **آمار و گزارش:** ۷ یا ۳۰ روز؛ موفقیت هر مقصد، پرانتشارترین‌ها، نمودار روزانه (متنی)، تاریخچه با فیلتر ناموفق.
- **تنظیمات:** روشن/خاموش‌کردن هر مقصد، «انتخاب خودکار بهترین متن» (برای هر پست ۳ متن می‌نویسد و Gemini بهترین را خودش انتخاب می‌کند؛ پیش‌فرض خاموش)، تعداد و ساعت پست روزانه، فاصله‌ی حداقل بین پست‌های صف.
- **گزارش عملیات:** ثبت هر کار مدیریتی (چه کسی، چه چیزی، کی).
- دستورها: `/status /post /products /queue /history /calendar /stats /settings /log /cancelqueue ID /retryqueue ID /off لینک /on لینک /myid /cancel`.

## ضدتکرار
- هر مورد صف با یک به‌روزرسانی اتمیک قفل می‌شود؛ دو فرایند هم‌زمان نمی‌توانند یک مورد را دوبار بفرستند.
- نتیجه‌ی هر مقصد بلافاصله ذخیره می‌شود؛ تلاش مجدد یا ریستارت، مقصدهای موفق را دوباره نمی‌فرستد.
- مورد گیرکرده در «در حال انتشار» بعد از ۱۰ دقیقه خودکار به صف برمی‌گردد.
- اسلات‌های چرخه‌ای مثل قبل با قفل `post_slots` یک‌بار اجرا می‌شوند. با تغییر ساعت‌ها، ساعت‌های گذشته‌ی امروز دوباره پست نمی‌شوند.
- خطای انتشار و پایان انتشارهای زمان‌بندی‌شده به ادمین‌ها در تلگرام اعلام می‌شود.
