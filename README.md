# ربات بله شهر سفال

پست خودکار ۵ محصول در روز (ساعت‌ها قابل تنظیم) در کانال بله، با عکس + متن هوش مصنوعی + دکمه‌ی «مشاهده در سایت».

## راه‌اندازی (به ترتیب)
1. **بله**: در @botfather ربات بسازید و توکن بگیرید. ربات را در کانال خود **ادمین** کنید (دسترسی ارسال پیام).
2. **Supabase**: پروژه بسازید → SQL Editor → محتوای `schema.sql` را اجرا کنید. از Settings > API مقدار `Project URL` و کلید `service_role` را بردارید.
3. **GitHub**: همه‌ی این فایل‌ها را در یک مخزن (ترجیحاً Private) آپلود کنید. فایل `.env` را هرگز آپلود نکنید.
4. **Render**: New > Web Service > مخزن را وصل کنید (Free). Build: `pip install -r requirements.txt` ، Start: `gunicorn bot:app --workers 1 --threads 4 --timeout 120 --bind 0.0.0.0:$PORT`
   در Environment، متغیرهای `.env.example` را وارد کنید.
5. **UptimeRobot**: یک مانیتور HTTP روی `https://<نام-سرویس>.onrender.com/health` با بازه‌ی ۵ دقیقه.
6. در بله به ربات پیام `/myid` بدهید، عدد را در `ADMIN_USER_IDS` بگذارید و ریست کنید. سپس `/start` بزنید تا منو بیاید.
7. **ورود محصولات (یک‌بار):** از پنل سایت: محصولات > برون‌بری (Export) > فایل CSV. در منوی ربات «ورود فایل CSV» را بزنید و فایل را به‌صورت Document بفرستید.
8. با `/post` یک پست آزمایشی بفرستید.

## پنل ادمین (فقط ADMIN_USER_IDS)
- `/start` منو: ➕ افزودن محصول با لینک · 📥 ورود CSV · 📊 وضعیت · 📤 ارسال فوری
- افزودن محصول جدید: دکمه‌ی ➕ و ارسال لینک (چند لینک زیر هم هم می‌شود). فقط همان یک محصول از سایت خوانده می‌شود. بدون دکمه هم اگر لینک سایت را بفرستید اضافه می‌شود.
- `/off لینک` خارج‌کردن محصول از چرخه (ناموجود شد) · `/on لینک` برگرداندن
- هیچ همگام‌سازی خودکاری با سایت وجود ندارد.

## نحوه‌ی کار چرخه
هر محصول `posted_count` دارد. همیشه از بین محصولاتی با کمترین تعداد پست انتخاب می‌شود؛ پس همه‌ی محصولات یک‌بار پست می‌شوند و بعد دور بعد شروع می‌شود. محصول جدید سایت خودکار وارد چرخه می‌شود و ناموجودها کنار می‌روند.
