# ربات بله شهر سفال (نسخه‌ی ۲)

پست خودکار ۵ محصول در روز در کانال بله: عکس + متن هوش مصنوعی + دکمه‌ی «مشاهده در سایت».
**هیچ سینک خودکاری با سایت وجود ندارد.** محصولات از فایل خروجی پنل ووکامرس وارد می‌شوند و محصول جدید با لینک اضافه می‌شود.

## راه‌اندازی
1. **بله**: در @botfather ربات بسازید، توکن بگیرید و ربات را در کانال **ادمین** کنید.
2. **Supabase**: SQL Editor → محتوای `schema.sql` (اگر قبلاً اجرا کرده‌اید، لازم نیست دوباره). `Project URL` و کلید `service_role` را بردارید.
3. **GitHub**: فایل‌ها را در مخزن Private آپلود کنید (`.env` هرگز).
4. **Render**: Web Service رایگان؛ در Environment این متغیرها را بگذارید:

| نام | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات بله |
| `ADMIN_ID` | شناسه‌ی **عددی** شما در بله (چند نفر: با کاما). به ربات `/myid` بفرستید تا بگوید |
| `CHANNEL_ID` | مثل `@mychannel` |
| `SUPABASE_URL` / `SUPABASE_KEY` | از Supabase |
| `GEMINI_API_KEY` | هر ۶ کلید با کاما جدا: `key1,key2,...` |
| `GEMINI_MODEL` | پیش‌فرض `gemini-2.5-flash` |
| `GEMINI_MAX_ATTEMPTS` | حداکثر تلاش برای ساخت یک متن (پیش‌فرض = تعداد کلیدها) |
| اختیاری | `ADMIN_USERNAME` (آیدی بله برای چاپ در پست)، `ADMIN_PHONE`، `POST_TIMES`، `SHOW_PRICE`، `ORDER_MODE`، `SITE_URL` |

5. **UptimeRobot**: مانیتور HTTP روی `https://<سرویس>.onrender.com/health` هر ۵ دقیقه.
6. به ربات در بله `/start` بدهید تا منوی مدیریت بیاید.

## پر کردن محصولات (یک بار) — فایل CSV
در پنل وردپرس: **محصولات ← خروجی گرفتن (Export)** ← فرمت CSV ← دانلود.
فایل را در بله به ربات بفرستید (به‌صورت Document) یا از منو «📥 وارد کردن فایل محصولات» را بزنید.
- فقط محصولات منتشرشده و موجود وارد چرخه می‌شوند.
- دوباره فایل دادن امن است: محصولات تکراری فقط به‌روز می‌شوند و شمارنده‌ی چرخه‌شان صفر نمی‌شود.
- فایل CSV لینک محصول ندارد؛ ربات `سایت/?p=شناسه` می‌سازد که وردپرس خودش به لینک اصلی هدایت می‌کند.

## محصول جدید
دکمه‌ی «➕ افزودن محصول (با لینک)» را بزنید و لینک را بفرستید (یا مستقیم لینک را بفرستید). فقط همان محصول با **یک درخواست** به سایت خوانده و اضافه می‌شود و در همان دور چرخه پست می‌شود.

## حذف از چرخه
«🗑 حذف محصول» ← لینک، شناسه‌ی عددی یا بخشی از نام. (محصول پاک نمی‌شود، فقط غیرفعال می‌شود.)

## منو
`/menu` · `/status` · `/post` پست فوری · `/add` · `/remove` · `/cancel` · `/myid`

## چرخه
هر محصول `posted_count` دارد و همیشه از بین کم‌پست‌ترین‌ها انتخاب می‌شود؛ همه‌ی محصولات یک‌بار پست می‌شوند و دور بعد شروع می‌شود.
